# 项目一：资料整理与可恢复备份

[项目总览](../README.md) · [源码](../../scripts/projects/organize.py)

## 要解决的问题

学习资料混放时，需要按用途分类，又要保留原始材料；备份还应证明能够恢复。这个项目生成三份小文件，让你观察完整流程。

## 先预测，再运行

```bash
bash scripts/study.sh project organize
```

输入自动生成在本次目录的 input/：课程笔记 TXT、测量 CSV、README Markdown。输出 organized/text/、data/、other/ 三类目录，以及 backup.tar.gz、restored/、manifest.json。

预计文件总数 3；分类后的副本和原件相同，恢复文件的 SHA-256 与清单一致，原文件仍保留。源码逐项检查这些条件。

## 如何阅读代码

1. 建立输入并写明数据内容。
2. 根据扩展名选择分类，使用 copy2 保留原件。
3. 生成相对路径和内容摘要清单。
4. 将分类目录归档，再按已知清单读取恢复。
5. 对照摘要验证每个文件，而不只检查压缩包存在。

## 自己动手

另建新程序，增加一份 JSON 资料和新的分类。预测文件数，再验证副本和恢复内容。接着解释：如果把 backup.tar.gz 放在同一磁盘，它能应对什么故障，不能应对什么故障？

## 完成标准

能解释输入与三类输出；会列出归档内容；可以指出源文件没有被移动；能修改一个分类规则并验证新结果。教学同盘备份不能应对整盘损坏；真实重要资料需独立备份位置。
