# 阶段任务：从照着做走向独立完成

[目标路线](START_HERE.md) · [课程总览](README.md)

这些是可选的自我检验，不是强制周作业。每阶段选 30～90 分钟做一次独立任务；第一次可以查帮助，第二次尽量只看自己的记录。源码另建在 scripts/ 下。

| 阶段 | 独立任务 | 完成证据 | 相关课程 |
| --- | --- | --- | --- |
| M1 日常与终端 | 建三个练习文件，其中一个路径有空格；复制、改名、搜索并归档 | 指出原件、副本与恢复文件，内容一致 | U01～U06、C01～C08 |
| M2 脚本与工具 | 新建带参数的统计工具，能处理正常、缺失与空输入 | 输出格式明确，各种状态可解释，不覆盖旧结果 | P01～P08、H01～H06 |
| M3 系统与网络 | 观察自己的进程与一个本机 HTTP 服务，分别制造缺路径和 HTTP 错误 | 给出 PID/端口/状态，结束自己的资源并记录 | S03～S05、N01～N05 |
| M4 工程化 | 为一个模型写边界测试，再构建并安装自己的 Python 包 | 测试通过，在源码目录外调用安装后的命令 | E01～E04 |
| M5 C++ 与协作 | 建一个库和测试，修复一次诊断出的错误；处理示例 Git 冲突 | CTest 结果、错误定位、干净提交与双方意图说明 | E05～E07 |
| M6 复现与项目 | 打包输入、源码、参数与结果，在新目录恢复并重跑 | 摘要一致，说明同环境与跨环境边界 | R01～R04、N06 |

## 如何自评

- **会操作：**能给出自己的正确输入，重复完成核心步骤。
- **会解释：**说清每个关键命令或函数的作用，以及环境与路径来源。
- **会排错：**故意改坏一个条件，能根据证据定位，修正后重新检查。
- **会迁移：**换一份输入或添加一个要求，仍能独立完成并解释局限。

四项都做到再记为 done；只跑现成脚本可记 learning，隔一段时间重做有困难可记 review。不能完成某项时，回到对应课程即可，无需重学整套。

## 示例：M2 的最小完成标准

输入至少两条合法值，算出可手算的均值；输入不存在时清楚报错；输入为空时不伪装成均值 0；输出文件已存在时保留原内容；说明选用的解释器和参数。最后换一组值，再验证结果。

保存一份[学习记录](../scripts/templates/study_record.md)，写出失败分支和解释。正式作品放 scripts/exercises/，运行输出放自己的仓库内独立目录。
